# Sponsorship Package Details - SCI 2026

## Package Tiers

### Platinum Sponsorship - LE 30,000 (EGP 200,000 for website)
- Logo displayed behind speakers in press conference as platinum sponsor
- One table for displays in 3' x 3' space (Platinum sponsors' area)
- Logo in Registration area (extra large size)
- Five attendee passes with sponsorship ribbons
- Acknowledgment during opening session as platinum sponsor
- Logo with direct link on conference website main page
- Logo with direct link on conference website sponsorship page
- Logo placement in conference materials
- Logo regularly displayed on LCDs during conference
- One page print ad in conference book
- Promotional item in conference bag (all brochures supplied by sponsor)
- Access to VIP area (Invited speakers, Noble Laureates, Companies presidents, etc.)
- Five tickets for Gala dinner
