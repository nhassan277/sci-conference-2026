# SCI 2027 Favicon Package Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the generic browser-tab icon with an original, simplified SCI 2027 symbol in navy and gold, delivered as a complete browser and mobile icon package.

**Architecture:** Generate one square master icon with a deep-navy field and a simple golden scientific orbit and leaf/light motif, with no typography. Produce favicon and app-icon raster variants from the verified master without cropping. Add a Web App Manifest and standard metadata links in `client/index.html` so desktop browsers, mobile browsers, and installed web apps use the same identity.

**Tech Stack:** AI image generation for the original master mark, Pillow for lossless aspect-preserving resizes, React/Vite public assets, HTML metadata, JSON manifest, Vitest.
