# خطة تنفيذ تحديث أيام ورش SCI 2027

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**الهدف:** عرض 6 أبريل 2027 كيوم ورش قبل المؤتمر و9 أبريل كيوم ورش بعده مع الإبقاء على الزيارة الاختيارية للمتحف المصري الكبير، من دون تحديد أسماء أو موضوعات الورش الآن.

**المعمارية:** ستصبح بيانات البرنامج في `sci2027Content.ts` هي المصدر الوحيد لأيام 6–9 أبريل. سيُحذف كتالوج أسماء الورش الحالي ويستبدل ببيانات عامة توضح أن برنامج الورش ومواعيده التفصيلية والتسجيل سيُعلن لاحقًا. ستستخدم الصفحة الرئيسية وصفحة البرنامج نفس البيانات وتفصلان بوضوح بين يومي الورش (6 و9) ويومي المؤتمر الرئيسيين (7 و8).

**التقنيات:** React 19، TypeScript، Wouter، Tailwind CSS، Vitest، Vite.

---

### المهمة 1: تثبيت التوقعات عبر اختبار فاشل

**الملفات:**
- تعديل: `client/src/data/sci2027Content.test.ts`

**الخطوة 1: كتابة اختبار فاشل**

إضافة اختبار يلزم المصدر بما يلي:

```ts
expect(sci2027Content.programme.map((day) => day.date)).toEqual([
  "6 April 2027",
  "7 April 2027",
  "8 April 2027",
  "9 April 2027",
]);
expect(sci2027Content.workshopProgramme.preConference.date).toBe("6 April 2027");
expect(sci2027Content.workshopProgramme.postConference.date).toBe("9 April 2027");
expect(sci2027Content.workshopProgramme.status).toContain("to be announced");
```

ويتحقق كذلك من عدم وجود أسماء الورش القديمة في مصدر المحتوى أو صفحتي البرنامج والرئيسية.

**الخطوة 2: تشغيل الاختبار للتأكد من فشله**

```bash
pnpm exec vitest run client/src/data/sci2027Content.test.ts
```

النتيجة المتوقعة: فشل، لعدم وجود 6 أبريل وبرنامج الورش العام، مع بقاء الورش المسماة حاليًا.
